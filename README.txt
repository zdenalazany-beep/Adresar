ADRESÁŘ V2

Soubory: index.html, app.js, style.css, manifest.json, ikony, Code.gs.

PC: aplikace musí být dostupná přes HTTPS. V Chrome otevři její adresu. Pokud se objeví ikona Instalovat v adresním řádku, klikni na ni. Aplikace se objeví v nabídce Start a lze ji připnout na hlavní panel.

Android: otevři stejnou HTTPS adresu v Chrome → ⋮ → Přidat na plochu / Instalovat aplikaci.

Google Sheet: Rozšíření → Apps Script → vlož Code.gs → spusť setup → Nasadit → Nové nasazení → Webová aplikace → spouštět jako Já → přístup podle potřeby. Zkopíruj URL /exec a vlož ji do app.js místo VLOZ_URL_APPS_SCRIPTU.

Fotografie se ukládají do složky „Adresář fotografie“ na Google Drive a do Sheets se uloží odkaz.

Pozor: veřejně přístupné API s přístupem „Kdokoli“ není vhodné pro citlivé osobní údaje bez autentizace.
